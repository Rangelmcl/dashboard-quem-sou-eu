# Dashboard Quem Sou Eu

Entrega 02 do meu portfólio — Técnico de Informática para a Internet (SESI, turma Ômega).

## Sobre a entrega

Um dashboard é um painel que reúne informações importantes em um só lugar, de forma fácil de ler. Nesta entrega, em vez de dados de uma empresa, o dashboard mostra **informações sobre mim**: números, gostos, trajetória e objetivos.

## O que tem no dashboard

**Indicadores (números em destaque, com contagem animada):**

- 15 anos de idade
- 12h seguidas jogando
- 2 anos de namoro
- 2º lugar na bolsa do SESI

**Painéis:**

| Painel | O que mostra |
|---|---|
| **Perfil** | Nome, cidade, curso e turma |
| **Do que eu gosto** | Jogos (Ark), academia e PC |
| **Minha trajetória** | Como entrei no SESI com a bolsa, a escolha da turma Ômega e onde estou hoje |
| **Minhas 5 faixas** | Uma crença, um valor, um talento, um medo e um sonho |
| **Futuro** | Quero trabalhar com programação e hardware |
| **Curiosidade** | Gosto de assistir MasterChef e Pesadelo na Cozinha |

## Como foi feito

- **HTML** para a estrutura da página.
- **CSS** para o visual: fundo preto, vermelho como cor de destaque e cards com borda e sombra, no mesmo estilo do meu portfólio. O layout se ajusta ao tamanho da tela, então funciona no computador e no celular.
- **JavaScript** só para a contagem animada dos números do topo.

Tudo fica em um único arquivo, o `index.html`, sem precisar instalar nada.

## Como ver

Baixe o `index.html` e abra no navegador. Se o repositório estiver com o GitHub Pages ativado, também dá para abrir pelo link do site.
